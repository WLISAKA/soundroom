# 声间 · Soundroom

生煎包，真的很好吃
自用 Windows 桌面音乐播放器。没有充值、广告或社交入口。

## 运行

构建后的便携版位于 `release/0.5.1/Soundroom-0.5.1-Windows.exe`，双击即可打开。
也可以运行 `release/0.5.1/win-unpacked/声间.exe`，此时需要保留同目录的所有文件。

源码运行需要 Node.js 22.12+：

```powershell
npm install
npm exec -- install-electron --no
npm run build
npm start
```

开发：`npm run dev`。打包：`npm run dist`。

## 使用

- 在「偏好与信息 → 配色风格」选择经典蓝或北欧暖白。北欧暖白使用暖灰白、炭灰、苔绿和木色，细字重、2px 圆角、宽松留白与 700ms 轻缓过渡。主题立即应用到主窗口和歌词小窗，并在下次启动时恢复。小窗专辑图向当前主题底色渐变。

- 在「本地音乐」选择音乐文件。支持 MP3、FLAC、M4A、AAC、OGG、WAV、Opus；歌曲保持在原位置，不复制或删除文件。
- 同步歌词读取音乐旁的同名 UTF-8 `.lrc` 文件。
- 点击歌曲封面进入完整播放页，点击歌词跳转到对应时间。
- 底部「歌词小窗」按钮打开始终置顶的播放器，专辑图铺满左侧高度，向右渐变到主题色，右侧显示歌曲、歌词和播放控制。拖动封面或文字区域可移动窗口，底部进度条可跳转。
- 小窗无系统白边。右下角可拖动调整大小；操作栏最左侧按钮在顺序与随机播放之间切换，与主窗口保持同步。
- 小窗换行时歌词会轻微滑入并淡入，跟随系统的减少动态效果设置。
- 在「偏好与信息」设置在线偏好音质。默认 HQ，按无损、HQ（320 kbps）、较高（192 kbps）、标准（128 kbps）的顺序向下回退，播放栏显示实际音质。
- 点击列表按钮打开队列，可调整顺序、移除或清空。支持随机、列表循环、单曲循环和顺序播放。
- 打开歌单后自动读完所有分页并显示进度，无需手动「载入更多」。点击任意歌曲播放时，整张歌单替换进播放队列，并从所选歌曲开始；「播放全部」从第一首开始，「加入队列」将整张歌单追加到现有队列并去重。
- 大歌单与队列按可见区域渲染，歌曲数据完整保留。分页失败时显示重试提示，不把部分结果当作完整歌单；切换页面会取消旧歌单的后续读取。已移除旧的 5000 首队列保存限制。
- 关闭主窗口后留在托盘继续播放。托盘右键或「偏好与信息 → 完全退出声间」退出进程。
- 再次打开会恢复队列、进度、音量和播放模式，并等待你手动播放。
- 支持键盘媒体键；主窗口非输入状态下可用空格播放／暂停。
- 全局快捷键：`Ctrl + Alt + 空格` 播放／暂停，`Ctrl + Alt + ←` 上一首，`Ctrl + Alt + →` 下一首。主窗口隐藏到托盘时仍可使用；「偏好与信息」显示实际注册状态，快捷键被其他程序占用时会注明。

## QQ 音乐接入

点击「连接 QQ 音乐」会打开独立的 QQ 音乐官方网页，在该窗口自行登录 QQ 账号。
完成后关闭登录窗口，播放器会尝试验证账号并加载歌单。也可在「偏好与信息」中刷新账号。
密码和验证码不经过播放器界面；登录会话由 Electron 的独立持久化会话保存在本机，不发送到开发者服务器。

已实现的接口适配包括：

- 我的喜欢、个人歌单、收藏歌单与分页读取；
- 歌曲搜索、专辑曲目、歌手歌曲；
- 按账号权限和偏好音质请求在线播放地址和同步歌词；
- 喜欢／取消喜欢、创建私密歌单、删除自己的普通歌单、增删歌单歌曲；
- 修改前核对账号、歌单归属和歌曲身份，写入后读取确认。失败或结果不明时提示实际状态。

用户已确认歌单同步可用。绿钻完整播放及其他账号写操作仍需按实际使用结果验证。非公开接口可能变动。

歌曲及音质可用性取决于 QQ 音乐对账号和所在地区提供的权限。在美国等地区不保证与中国相同的曲目可用性。软件不提供地区伪装或版权／会员限制绕过。

## 网易云音乐接入

在「网易云歌单」或「偏好与信息」中连接网易云音乐，在官方网页完成登录后关闭窗口。QQ 音乐和网易云音乐可同时登录。
在搜索框右侧选择音源。网易云支持读取自建和收藏歌单、搜索、专辑与歌手页面、播放和同步歌词。用「加入队列」可把不同来源的歌曲放进同一队列。

## 数据与退出

默认数据目录是 Windows 用户的 `%APPDATA%/soundroom`（实际以 Electron 返回路径为准）。
`library.json` 保存本地曲库引用、队列、播放进度和偏好音质。两个在线账号的登录状态分别保存在各自的本地会话目录中。
在应用中退出一个账号会清除对应会话的登录状态。移除本地音乐只移除引用。

## 验证

```powershell
npm test
npm run smoke
npm run smoke:collections
node scripts/probe-qq.cjs
```

单元测试覆盖歌词时间轴、歌曲标识、写入确认与账号／歌单归属校验。
桌面集成测试在 `.runtime` 内创建独立测试曲库和静音 WAV 文件，实际验证导入、播放、进度、歌词、小窗、托盘、恢复和渲染器隔离，不接触你的真实账号。
网络探测只读取公开搜索、专辑和歌手数据，不登录或修改账号。

`smoke:collections` 使用隔离的模拟 QQ 数据，验证 251 首与 5105 首歌单自动聚合、点击任意歌曲完整入队、追加整张歌单、长列表滚动、队列保存恢复，以及分页失败、重试和取消加载。测试不会访问真实 QQ 账号。
